## หมายเหตุสำหรับผู้ทดสอบ

- ข้อมูลทั้งหมดเป็น mock (`src/features/village/data/villageData.js`) ค่าเริ่มต้นจะเหมือนเดิมทุกครั้งที่โหลดหน้าใหม่ — แปลงนาที่เพิ่ม/รายการขายที่ส่งจะหายไปเมื่อรีเฟรช เพราะแก้ที่ array ใน memory ตรงๆ ไม่มี backend เก็บถาวรจริง
- AI วินิจฉัยโรคเป็น scripted demo ตอบตามเงื่อนไข keyword หรือมีการแนบรูปเท่านั้น ไม่ใช่โมเดลจริง
- ปุ่ม/ลิงก์ทั้งหมดที่เคยเป็น placeholder (ดูทั้งหมด/ขายข้าวใหม่/ดูประวัติการรับเงิน/เมนูย่อยต่างๆ) ตอนนี้ผูก action จริงหมดแล้ว (ดูตาราง 9) — ถ้าเจอปุ่มไหนกดแล้วไม่มีอะไรเกิดขึ้นถือเป็นบั๊กที่ต้อง report ได้เลย
- ยังไม่มีการล็อกสิทธิ์ตาม role ต่อ route (V-04) — เป็นข้อจำกัดที่รู้อยู่แล้ว
