## หมายเหตุสำหรับผู้ทดสอบ

- ข้อมูลทั้งหมดเป็น mock (`src/features/village/data/villageData.js`) ตัวเลข/ราคาที่เห็นจะเหมือนเดิมทุกครั้ง ไม่ใช่ของจริง
- AI วินิจฉัยโรคเป็น scripted demo ตอบตามเงื่อนไขคำว่า "ใบเหลือง" หรือมีการแนบรูปเท่านั้น ไม่ใช่โมเดลจริง
- ปุ่มที่ยังไม่ผูก action จริง (ดูทั้งหมด/ขายข้าวใหม่/ดูประวัติการรับเงิน ฯลฯ) กดแล้วไม่มีอะไรเกิดขึ้น — เป็นที่ทราบอยู่แล้ว ไม่ใช่บั๊กที่ต้อง report
